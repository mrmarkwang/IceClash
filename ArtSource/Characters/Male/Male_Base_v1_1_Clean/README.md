# Male Base v1.1 Clean art source

This directory contains the Blender working file and deterministic audit/cleanup scripts for the additive `Male_Base_v1_1_Clean.fbx` asset.

The Unity v1 FBXs and validation assets are immutable inputs. The Blender file preserves the imported armature and uses no automatic bone orientation, applied transforms, automatic weights, remeshing, or animation export.
